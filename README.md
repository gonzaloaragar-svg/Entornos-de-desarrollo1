# Actividad Módulo 1 - Conceptos y Paradigmas de Programación

Este repositorio contiene las tareas prácticas sobre los fundamentos de la programación. El proyecto incluye un archivo `INFORME.md` donde se analizan:
- Conceptos básicos: código fuente, objeto y ejecutable, junto con las fases de un programa.
- Clasificación de los lenguajes de programación según su nivel de abstracción y paradigma.
- Ejemplos prácticos y una comparación entre el enfoque imperativo y el declarativo aplicados al código y a actividades de la vida diaria.
